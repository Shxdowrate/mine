# Solo Rust

Fabric-мод для Minecraft 26.1.x: одиночный выживач в духе Rust.

## Что уже есть (этап 1)
- Каменные, металлические и серные глыбы на поверхности по всему миру
- Серная руда → сера в печи; порох: 2 серы + уголь/древесный уголь = 3 пороха
- Срубка целиком: топором рубишь одно бревно — падает всё дерево, киркой ломаешь руду — ломается вся жила (зажми Shift, чтобы ломать по одному блоку)

## В планах
- Дороги по всей карте, бочки и ящики с лутом, скрап и компоненты, переработчик
- Верстаки 1–3 уровня, оружие и патроны
- Карьеры на дизеле, турели, аирдроп по сигнальной шашке

## Силовая броня
Пять поколений костюмов (вкладка творческого режима **«Силовая броня»**). Надень все 4 части одного поколения — костюм включится:
слева вверху появится энергия, а в инвентаре — встроенные системы. Сними — системы исчезнут.

| Костюм | Полёт | Встроенные системы |
|---|---|---|
| Mk I «Кузня» | нет, усилители прыжка | огнемёт, наручная ракета |
| Mk II «Прототип» | да | репульсор, сканер |
| Mk III «Авангард» | да | репульсор, грудной луч, микроракеты, наплечные пулемёты, лазер-резак, ловушки, сканер |
| «Титан» | да, медленно и тяжело; огромный, при приземлении и из пике — ударная волна | ударный молот, тяжёлые ракеты, грудной луч, пулемёты, сканер |
| «Кейс» (лёгкий) | нет, усилители прыжка | репульсор, сканер |
| «Нанорой» | да, самый быстрый | всё оружие Mk III + нанолезвие, нанощит, нанопушка |
| «Сингулярность» | да | ядра: гравитация, время, пространство, материя, разум, жизнь; ультимейт «Коллапс»; пассивно спасает от смерти |
| Облачение архимага | левитация | мистический разряд, порталы, рунический щит, астральная форма, петля времени |
| «Апекс» | да, быстрее всех, звуковой удар | лучи из глаз, звуковой хлопок, захват и бросок; почти неуязвим, пока сыт |
| «Бурильщик» | нет | бур 3×3, сейсмоскан, световая шашка; ускоренная добыча |
| «Прораб» | да | стена, мост, платформа, снос (блоки — из второй руки); длинные руки |
| «Глубоководный» | нет, быстро плавает | торпеды, подводный резак, сонар; дышит под водой |
| Костюм хаоса | да | разряд, цепь, волна (выжившие зависают), управляемый вихрь, метеоры, разлом, сфера, проклятие, взрыв хаоса, сканер |
| «Призрак» | нет, двойной прыжок | маскировка, крюк-кошка, сканер; без урона от падения |

- **Полёт:** двойной пробел — взлёт, **Ctrl** — форсаж. Полёт и выстрелы тратят энергию, на земле она восстанавливается.
- **Оружие:** ПКМ — выстрел; у огнемёта, лазера, пулемётов и щита — держи ПКМ; грудной луч и нанопушку держи для заряда и отпусти.
- **Как надеть:**
  - Mk I — руками, по частям;
  - Mk II / Mk III (и любой другой) — **сборочная станция**: встань рядом, ПКМ — манипуляторы соберут костюм на тебе. В костюме ПКМ по пустой станции — снять его на станцию. **V** — костюм прилетит со станции к тебе;
  - «Кейс» — ПКМ по кейсу или **G**, костюм раскрывается на тебе; **G** в костюме — сложить обратно в кейс;
  - «Нанорой» — нанокапсула, **G** — костюм растекается по телу, ещё раз **G** — убрать;
  - «Титан» — маяк вызова: ПКМ — капсула падает с неба туда, куда смотришь, ПКМ по капсуле — надеть; **G** — отправить обратно и получить маяк.
- **Шлем:** **H** — включить/выключить интерфейс, **J** — меню шлема. Компас, здоровье/броня/координаты/скорость/биом, данные о цели под прицелом, обводка мобов сквозь стены (враги — красные, мирные — зелёные, игроки — голубые) и рамки на рудах, сундуках и спавнерах. Что показывать — выбирается в меню; дальность растёт с поколением шлема.
- **Крафт:** энергоядро → Mk I (железо + скрап + ядро) → каждое следующее поколение улучшается из предыдущего на верстаке:
  - рабочие костюмы и «Призрак» — из Mk I;
  - «Апекс» — из Mk II;
  - «Сингулярность» и костюм хаоса — из «Нанороя»;
  - архимаг — из кожаной брони, золота и лазурита.
- Текстуры генерирует `tools/gen_suit_textures.py` — цвета поколений меняются в `PALETTES`.

## Сборка
Каждый пуш собирается в GitHub Actions: готовый `.jar` лежит в артефактах запуска (вкладка **Actions** → последний запуск → **solorust-jar**).
Пуш тега `v*` (например `v0.1.0`) дополнительно создаёт релиз с jar-файлом.

Нужны: Fabric Loader ≥ 0.18.4 и Fabric API для 26.1.x.
